## 💻 Executar Localmente

### Pré-requisitos

- Node.js 18+ 
- npm ou bun

### Instalação

1. Clone o repositório:
```bash
git clone https://github.com/seu-usuario/letus-dev.git
cd letus-dev
```

2. Instale as dependências:
```bash
npm install
# ou
bun install
```

3. Execute o servidor de desenvolvimento:
```bash
npm run dev
# ou
bun run dev
```

4. Abra no navegador: `http://localhost:3000`
